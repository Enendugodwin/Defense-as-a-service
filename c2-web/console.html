Agent troubleshooting

Persistent session

Open one line-oriented shell session to an enrolled agent. Commands share shell state (for example, the working directory). This is not a full TTY; interactive editors and password prompts are unsupported.

Commands run as the agent’s Windows/Linux user. The session expires after 15 minutes of inactivity. Keep this console bound to localhost and protect the admin API key.
No session
Choose an enrolled agent and open a session.

Results are stored in PostgreSQL, separately from OpenSearch logs. Command text is not stored in the result record. Use exit to close the shell; the Close button ends the session.
